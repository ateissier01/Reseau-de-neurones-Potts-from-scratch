Ce projet concerne le développement from scratch d'un réseau de neurones de Potts. Il s'agit d'un réseau similaire à un réseau de neurones de Hopfield mais qui peut prendre plus de valeurs différentes (pas seulement 0 ou 1). J'ai rajouté la possibilité de réduire les connexions entre neurones: si les neurones sont trop éloignés, il n'y a pas de connexion ce qui permet de réduire le nombre de paramètres stockés. Pour l'instant, je stocke la matrice entière bien qu'elle soit symétrique. Une amélioration serait de ne stocker que la partie supérieure ou inférieure de la matrice. L'objectif de ce projet était de me permettre d'apprendre les fondements de ce type de réseaux de neurones.
